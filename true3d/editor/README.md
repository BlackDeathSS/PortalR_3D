# TRUE3D Chamber Editor

Open `index.html` locally in a current browser. No server or dependencies are
required.

The editor creates the `T3D1` map format loaded by `TRUE3D06`. This milestone
uses up to eight axis-aligned convex rooms, six independently colored faces per
room, a player spawn, and an optional initial orange/blue portal pair. Runtime
portal placement can move either portal to any floor, ceiling, or wall.

Export `T3DLVL1.8xv` and transfer it to calculator archive beside
`TRUE3D06.8xp`. Missing or invalid AppVars use the built-in two-room test map.
