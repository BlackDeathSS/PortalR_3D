# PortalR 3D Studio

PortalR 3D Studio is the shared project and level editor for the production
`PORTAL3D` raycaster and `T3D3DEV` true-3D engine. It authors multiple levels,
generates the engine level tables, invokes CEdev, and creates transfer-ready ZIP
packages from one interface.

## Start the editor

From the repository root in PowerShell:

```powershell
.\editor\start-editor.ps1
```

The launcher opens `http://127.0.0.1:8765/`. Keep its PowerShell window open
while editing or building. Python 3 and the CEdev toolchain (`make` and
`cedev-config`) are required. The launcher automatically uses the Python runtime
bundled with Codex when it is present.

## Project workflow

1. Switch between **Portal3D** and **T3D3** in the left rail.
2. Add, duplicate, select, or delete packaged levels.
3. Edit the selected level:
   - Portal3D uses a clickable 15-by-15 wall grid, spawn placement, heading,
     and as many as ten directed built-in portal links.
   - T3D3 uses one to eight axis-aligned rooms, six face colors per room,
     a player spawn, and the optional initial orange/blue portal pair.
4. Save the complete project as JSON when you want a portable source copy.
5. Choose **Build Portal3D**, **Build T3D3**, or **Build both**.
6. Download the generated ZIP from the build console.

Every authored level is embedded in the program `.8xp`. No separate level
AppVars are needed for an editor-built package. Each engine shows its packaged
levels in a startup selector; use Up/Down and `2nd` to play, or `Clear` to exit.

The combined package contains:

```text
Portal3D/PORTAL3D.8xp
T3D3/T3D3DEV.8xp
project.json
README.txt
```

Generated engine tables are written to `src/generated_levels.c` and
`t3d3/src/generated_levels.c`. They are ordinary build inputs, so command-line
`make` builds the same levels last generated by the studio.

## Format limits

- A game package supports 1 to 16 levels.
- Portal3D maps are fixed at 15 by 15 and require an unbroken solid border.
- Portal3D portal endpoints must be wall cells, with only one directed entry
  portal per wall cell.
- T3D3 supports 1 to 8 rooms per level and Q8.8 world coordinates from -128
  through approximately 127.996.
- T3D3 rooms must be at least two world units wide on every axis.

The build service listens only on `127.0.0.1`; it is not exposed to the local
network.
